# Contributing to FairBank AI

Thank you for your interest in contributing to FairBank AI!

## Development Setup

1. Clone the repository
2. Set up each service (frontend, backend, ai-service) as described in README.md
3. Ensure all environment variables are configured

## Code Style

- Frontend: Follow React best practices
- Backend: Follow Node.js/Express conventions
- AI Service: Follow PEP 8 for Python

## Testing

- Write tests for new features
- Ensure all tests pass before submitting PR

## Submission

This project is part of GHCI 2025 - Round 2 Submission.
