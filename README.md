# FairBank AI - Ethical & Transparent Loan Decision System

## Theme 2: Ethical AI in Banking: Building Trust & Transparency

FairBank AI is a comprehensive loan decision-making platform that transforms traditional "black box" AI systems into transparent, fair, and explainable decision-making tools.

## 🎯 Key Features

- **100% Explainable Decisions:** Every loan decision includes SHAP-based explanations
- **<2% Fairness Gap:** Automated bias mitigation ensures equitable treatment across demographics
- **Full Auditability:** Comprehensive logs enable regulatory compliance
- **Real-Time Monitoring:** Continuous fairness tracking prevents bias emergence

## 🏗️ Architecture

- **Frontend:** React.js + TailwindCSS + Framer Motion
- **Backend:** Node.js + Express.js
- **AI Microservice:** Python + Flask (Scikit-Learn, SHAP, AIF360)
- **Database:** MongoDB
- **Deployment:** Vercel (Frontend) + Render (Backend/AI)

## 🚀 Quick Start

### Prerequisites
- Node.js (v18+)
- Python (v3.9+)
- MongoDB (local or cloud)
- npm or yarn

### Frontend Setup
```bash
cd frontend
npm install
npm start
```

### Backend Setup
```bash
cd backend
npm install
npm run dev
```

### AI Service Setup
```bash
cd ai-service
pip install -r requirements.txt
python app.py
```
